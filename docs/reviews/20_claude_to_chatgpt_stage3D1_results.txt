What 3D-1 adds (spec v1.7, Section 7, "3D-1 in detail"; the owner's words
are in Section 1, kept apart from the interpretations)
1. Goals: "goal f7 2", ordered sets "goal f7 g7 h7 3", "goal king 2" (the
   squares next to the enemy king, board order); limit L = own moves 1-4;
   "goal" / "goal off". PASS only, labelled hypothetical on every report.
2. CONDITION IF / ELSE (the owner's words for true / false): REACH (an S
   piece on G) and PROTECTED (and another S piece protects G), within L.
   PIECE (this piece alone) and SIDE (any S pieces) kept separate.
3. "routes": per goal square, NOW counts, each S piece's PIECE line, every
   shortest route of each piece, SIDE REACH / PROTECTED, every shortest
   protected (coordinated, "width") route, the arrival vector (OWN,
   PROTECTORS, ATTACKERS) and DOMINATED (no worse in all, better in one);
   then SQUARE lines for every square and FIRST-IF (the owner's if / else
   if order). A later IF is never turned into ELSE by an earlier one.
4. Marks in the lists (the owner's "third list"): after selecting a piece,
   each destination; after a preview, every move of every S piece in the
   AFTER position: PIECE / SIDE CONDITION IF <sq> MOVES <n> or ELSE;
   REACHED when the previewed move reaches the goal.
5. Review 17: two separate ORDER views, as fields beside CONDITION:
   A. route length: ORDER IF (fewest moves present) / ELSE IF / ELSE
      (most), NONE when not reached within L;
   B. "distance on": after selection and after a preview (all pieces of
      both sides in the AFTER position), each legal move with DISTANCE d =
      max(|rows|, |files|), ORDER IF (fewest squares) / ELSE IF / ELSE
      (most); equal distances get the same label; one distinct distance:
      IF only; no legal move: NO-MOVES; knight moves marked JUMP (one move,
      displacement 2); castling marked CASTLE with the rook's move (king's
      2 squares); a piece of the side not to move listed as if its turn.
   Neither order is called "better"; the raw numbers are always printed.

PASS definition (review 16, point 4): every own move is a legal move with S
to move (generate_moves): no jumping over pieces, the own king never left in
check, captures remove the piece, kings are never captured (the generator
does not produce king captures; checked); en passant cleared after each own
move. Opponent pieces stay; they can be captured.
