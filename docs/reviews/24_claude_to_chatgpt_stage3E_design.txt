2. Claude's reading
- In the distance order (review 17), a 1-square move that captures a pawn
  is IF and a longer move that captures the queen may be ELSE. The owner
  points out that taking the pawn first is not logical when the queen can
  be taken, so he adds a NEW, separate order by the value of the captured
  piece, greatest to least: the highest captured value is IF, each smaller
  distinct value ELSE IF, the smallest ELSE. ("The motion to if is false
  and the motion to else is true" = in this new order the queen capture
  becomes the IF.)
- Values are therefore shown (question 3 answered): the conventional
  P 1, N 3, B 3, R 5, Q 9; a king is never captured and has no value.
- Example: Nxq (9) VALUE ORDER IF, Bxn (3) ELSE IF, Pxp (1) ELSE;
  a knight and a bishop capture (both 3) get the same label; a move that
  captures nothing is outside the chain (CAPTURES none).

3. Proposed 3E (Version 13)
A. The value order: "value on" / "value off" / "value" (like "distance").
   After selecting a piece and after a preview, every legal capture is
   listed with CAPTURES <type> VALUE <v> ORDER IF | ELSE IF | ELSE (by the
   captured value, greatest to least, per piece, same labelling rules as
   review 17); non-captures: CAPTURES none. Shown beside, never replacing,
   the distance order and the route order.
B. Exchanges on one square: "exchange <square> [N]" (N = 1..8 captures,
   the user's limit). From the current position, every sequence of
   captures on that square, the side to move first, sides alternating;
   after each capture the side to move may also stop. No capture order is
   preferred (Claude does NOT use the textbook "least valuable attacker
   first" rule, because it is a value judgement); every legal order is
   listed:
     EXCHANGE BEGIN <square> LIMIT N
     SEQUENCE <captures...> CAPTURED White <types> Black <types>
              MATERIAL White <sum> Black <sum>      (values logged only)
     ... one line per sequence (each stopping point is a sequence)
     FIRST <capture> VALUE <v> ORDER IF|ELSE IF|ELSE   (the owner's value
              order for the first capture)
     SUMMARY SEQUENCES <n>  LIMIT N
     EXCHANGE END
   Checks, pins and en passant follow the normal legal moves; a sequence
   stops when no legal capture on the square remains or at checkmate.
C. "Material at risk on arrival" (left open in 3D-1): for each ROUTE line,
   AT-RISK <value of the arriving piece> when at least one enemy piece
   attacks the goal square on arrival, else AT-RISK 0. Raw value only.
